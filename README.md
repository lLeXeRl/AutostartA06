# 长安启源 (Changan Qiyuan) — русский перевод

Приложение: `com.changan.oushangCos1`, версия 4.0.2.

## Пилотная сборка

`dist/qiyuan_4.0.2_ru_pilot.zip` + `.z01`…`.z04` — многотомный архив с APK
(собирается в ZArchiver: откройте `.zip` и распакуйте).

Переведено **463 строки** раздела управления автомобилем: двери, окна, багажник,
климат, зарядка, состояние авто, видеонаблюдение, отслеживание угона, OTA.
Перевод подключён как локаль `values-ru`: он появится, только если язык телефона — русский.

### Установка
1. Удалите оригинальное приложение (подпись другая, поверх не встанет).
   Вход в аккаунт придётся выполнить заново.
2. Установите `qiyuan_4.0.2_ru_pilot.apk`.
3. Проверьте: запускается ли, получается ли войти, работают ли команды авто.

### Ограничения
- Приложение защищено 爱加密 (ijiami): код зашифрован. Тексты, «зашитые» в код, перевести нельзя.
- Экраны на Compose (`assets/composeResources/*.cvr`) индексируются по смещениям байтов
  из зашифрованного кода, их не трогаем.
- Сборка подписана тестовым ключом. Защита или сервер могут отклонить такую подпись.
  Для этого и нужен пилот.
- Автообновление из магазина перезапишет перевод.

## Сборка
```
./tools/build.sh 长安启源_4.0.2.apk
```
Переводы лежат в `translation/ru/*.json` (ключ ресурса → русский текст).
